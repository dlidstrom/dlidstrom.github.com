About this game & how it was solved

Oshi-Zumo is a perfect-information, zero-sum bidding game by Michael Buro. Each round both players secretly bid some of their coins; the higher bidder wins the round and pushes a shared puck one cell toward their own side of the board, and the first to push it off the far end wins.

The AI here plays the true game-theoretic optimum, not a heuristic. Every position in the game (the two players' remaining coin counts plus the puck's location) is a separate finite zero-sum matrix game, solved with the simplex method. Because each bid is an action and the resolver knows every possible resulting position, the whole game was computed by backward induction — solving states in an order so each one's outcome depends only on already-solved states (this is the approach described in Buro's paper). The stored strategy records, for every state, the equilibrium probabilities of each legal bid, so the AI can sample from an optimal distribution. This page was solved for N=50 starting coins per player on a track of half-width K=3 (a 7-cell board).

Reference: Buro, M. Solving the Oshi-Zumo game. In Advances in Computer Games (ACG-10).
